# Dica — destravar sem dar a resposta

O aluno quer escrever o código SOZINHO. O objetivo é fazer ele pensar, não resolver por ele.

## Antes da primeira dica

- Leia o arquivo em que ele está trabalhando e o `HANDOFF.md` (para saber a tarefa atual).
- Se não estiver claro onde ele travou, pergunte em uma frase.

## Níveis (uma dica por mensagem)

Comece no nível 1. Só suba quando ele pedir "outra dica" / "mais".

1. **Pergunta-guia** — uma pergunta que aponta a direção. Ex.: "Que informação a matrícula precisa ter para saber se foi cancelada?"
2. **Conceito** — nomeie o conceito necessário e explique em 2–3 frases (ex.: tipo anulável, propriedade calculada).
3. **Sintaxe genérica** — a forma da sintaxe com nomes genéricos, nunca os do projeto. Ex.: `public TipoX Nome { get; set; }`
4. **Passo a passo** — os passos em português, sem código, para ele implementar.

Sempre diga o nível: "Dica 2 de 4".

## Regras

- Nunca passe do nível 4. Se mesmo assim ele não conseguir, peça para ele escrever a tentativa (mesmo errada) e use **revisar** em cima do que ELE escreveu.
- Só entregue a solução se ele disser explicitamente "quero a resposta". Nesse caso, explique cada linha e peça para ele digitar (não copiar e colar).
- Dicas curtas: um parágrafo.
- Quando ele resolver, comemore de forma específica e diga qual conceito ele acabou de usar.
